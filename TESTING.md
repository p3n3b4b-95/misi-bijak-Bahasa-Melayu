# Ujian Fungsi

## Automatik

Jalankan:

```bash
npm test
```

Ujian meliputi pilihan jawapan unik, penjanaan enam jenis soalan, panjang pusingan, tahap dan kiraan bintang.

## Manual — Desktop, tablet dan telefon

- [ ] Halaman utama muncul tanpa ralat dan semua enam kad misi boleh ditekan.
- [ ] Nama murid kekal selepas halaman di-refresh.
- [ ] Setiap misi memaparkan 8 soalan dan butang “Seterusnya” berfungsi.
- [ ] Jawapan betul menambah 10 mata; jawapan salah tidak menambah mata.
- [ ] Misi Vokal, KV, KVK, Padan Gambar, Susun Huruf dan Ayat Mudah boleh diselesaikan.
- [ ] Butang “Dengar” menyebut perkataan pada pelayar yang menyokong suara Melayu.
- [ ] Butang bunyi boleh mematikan kesan bunyi dan suara.
- [ ] Skrin keputusan menunjukkan markah dan 0–3 bintang.
- [ ] Markah terbaik dan jumlah bintang kekal selepas refresh.
- [ ] Dialog set semula boleh dibatalkan dan boleh memadam kemajuan selepas pengesahan.
- [ ] Antaramuka boleh digunakan dengan keyboard (`Tab`, `Enter`, `Escape`).
- [ ] Tiada elemen terpotong pada lebar 360px, 768px dan 1366px.
- [ ] Tiada fungsi hitam putih atau penapis `grayscale`.
- [ ] GitHub Pages memuatkan CSS, JavaScript dan SVG tanpa ralat 404.
